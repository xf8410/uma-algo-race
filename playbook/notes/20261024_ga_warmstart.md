# GA 暖启赛马：248 首轮 +161.4，GA→GA→GA 三轮叠加到 65062.0（+388.5）

> 来源：`uma-algo-race` 分支 `workbench/opt-ga`（2026-10-24/25）
> 动机：用户「继续用 ga 算法迭代手写逻辑，看看能不能更高分」；GA 是 r8 71415.6
> 的产地，但 uma-algo-race 的优化器名单里一直没有 GA。
> 纪律：「加算法 = 在已经提升过的冠军参数上叠加，不许独狼跑」「没有提高立马换」。

## 一、老家 GA 怎么迭代的（本次复刻依据）

逐行对照 `umaai-rs/crates/umasim/src/genetic_optimizer.rs`：

| 算子 | 老家值 | 本次实现 |
| --- | --- | --- |
| 精英保留 | 4/60 ≈ 7% | `max(1, round(0.07·pop))` |
| 锦标赛选择 | k=3，无放回，分高胜，并列取小下标 | 同 |
| 均匀交叉 | 0.9，逐基因 50/50；不交叉克隆父本 A | 同 |
| 高斯变异 | 每基因概率 1/N，σ×区间宽 | 同（N=45） |
| σ 退火 | 0.15 → 0.03 线性 | 同（gens_hint=20） |
| 停滞回升 | 连续 5 代无提升 → σ 回 0.15 | 同 |
| 初始化 | 个体 0/1 = 锚点，其余随机 | 个体 0 = 暖启冠军，其余 冠军+N(0,σ0)（暖启纪律） |

差异：老家 77 基因含 None 态/布局/配卡；本实验室空间是 45 维连续自由字段
（bool 与 preset 固定）。预算由 `warmstart_race --n-iter` 控制，代数 = 预算/pop。

## 二、协议

- 暖启锚：`data/seeds/seed_xnes_best.toml`（xNES 冠军，full 重放 **B=64673.5**）
- CRN：bench seed=42，full=7 build×100 局 + holdout 43；fitness=mean−800·fail
- GA：pop=8，σ0=0.15；30/128/248 次评估三档（30≈3 代，128=E2b pop8×16 代，248≈30 代）
- 判定：p<0.05 且 meanΔ>+150 → promote；否则 mild/n.s.
- 二阶段：锚换成 `seed_ga_best.toml`（64913.4），预算 128×10 seed，其余同协议

## 四、口径警示：71000 是旧核心

用户指出历史最高 71415.6。用当前代码原样重放当年 r8 冠军（基因哈希
9d8ce67d58616c83 + 配卡 303174/303124/303044/303064/302894）：

| 口径 | 旧核心（2026-09） | 当前核心（2026-10-25） |
| --- | ---: | ---: |
| 冠军单卡组×60 局均值（GA fitness 口径） | 71415.6 | **67529.4** |
| 7 卡组×100 局（赛马场 full） | — | **64287（uma 111501）/ 64493（uma 106402）** |

所以 64.8k 不是退步，是同一 71k 锚在当前核心上的值；当前核心上 xNES 冠军
（64673.5）已经比旧 71k 冠军重放（64287）高 +386。跨核心比绝对分无意义，
本分支一律用「当前核心 + 冠军重放定标 B」计 Δ。

## 五、判读

1. **GA 需要种群预算**：30 次评估只有 3 代，n.s.；128 次（E2b 档）转正；
   248 次（30 代）稳定过 +150 线。用 30 次的结论否定 GA 是预算错配。
2. **248 是当前最有性价比档**：比 128 多 +25.7 Δ，计算约 2 倍；10/10 全正，
   std 37.4（比 128 略大，探索更广）。
3. **增益来源**：轨迹显示 128 档到最后一轮仍在提升（seed7 在第 127 次才刷新），
   属于预算受限而非收敛；248 档继续印证。
4. **GA→GA 叠加成立且尚未触顶**：二阶段 +36.3、三阶段 +30.1，两轮都全正，
   三阶段 std 只有 9.1（p=3.3e-05）。每轮约 +30 的增益不是噪声，而是
   在当前 45 维空间里持续的小步精修；不过单轮收益已从 +161 降到 +30。
5. **下一步**：三阶段证明「多轮小预算精修」可叠加，值得试 512 一次
   （pop16×32 代，单轮覆盖更广），以及继续第 4/5 轮看何时真正平台化。
   跨算法接力（GA 冠军回灌 xNES/TPE）仍是另一条对照线。
